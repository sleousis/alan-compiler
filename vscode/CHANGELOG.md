# Changelog

## 1.0.0

First release.

- Highlighting, bracket matching and comment toggling for `.alan` files.
- Live errors while typing, with the compiler's messages and lines, and compiler errors on save.
- Completion, snippets, hover, signature help, go to definition, find all references, highlights and an outline.
- Rename and formatting.
- Run, Build and Show IR commands, with the play button in the editor title.
- Debugging with breakpoints and variables through CodeLLDB.
- Compiler install and update from VS Code, natively or inside WSL on Windows.
